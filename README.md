# 🛒 هايبر – نظام إدارة سوبرماركت احترافي

## 📌 نبذة عن التطبيق
**هايبر** هو نظام إدارة سوبرماركت متكامل يعمل بدون إنترنت، مصمم خصيصاً للمتاجر الصغيرة والمتوسطة.
يتميز بالسرعة العالية، السلاسة، والواجهة العربية الكاملة (RTL) مع ثيم **Liquid Glass** الحديث.

تم تطويره باستخدام **Flutter** ليعمل بكفاءة عالية على أجهزة Android، مع نظام قاعدة بيانات محلية فائقة السرعة (SQLite).

## 🚀 المميزات الرئيسية

### 🔐 نظام تسجيل دخول ذكي
- تسجيل دخول عبر PIN (4 أرقام)
- إمكانية تعطيل PIN من الإعدادات
- حماية كاملة للبيانات
- PIN الافتراضي: `1234`

### 🛍️ إدارة المنتجات
- إضافة / تعديل / حذف المنتجات
- دعم QR و Barcode
- تحديد سعر شراء وسعر بيع
- إدارة المخزون بالكميات
- تنبيه نقص المخزون
- بحث سريع جداً بالاسم أو الباركود
- تحديث تلقائي للمخزون عند البيع

### 🧾 نظام كاشير (POS) سريع جداً
- مسح QR أو Barcode بالكاميرا
- إضافة فورية للسلة
- تعديل الكمية بسهولة
- خصم نسبة أو مبلغ
- حساب الإجمالي تلقائياً
- حفظ الفاتورة خلال أجزاء من الثانية
- دعم الدفع: نقدي

### 📑 إدارة الفواتير
- عرض جميع الفواتير
- فلترة حسب التاريخ
- عرض تفاصيل الفاتورة
- تنفيذ عملية مرتجع (Refund)
- إعادة الكميات للمخزون تلقائياً

### 📦 إدارة المخزون
- تحديث فوري بعد كل عملية بيع
- زيادة تلقائية عند التوريد
- سجل كامل لحركة المخزون:
  - بيع
  - توريد
  - تعديل يدوي
  - مرتجع

### 📊 تقارير احترافية
- تقرير مبيعات يومي
- تقرير مبيعات شهري
- إجمالي الأرباح التقريبية
- أكثر المنتجات مبيعاً
- تنبيهات المنتجات منخفضة المخزون

### ⚡ أداء فائق السرعة
- يعمل بدون إنترنت بالكامل
- قاعدة بيانات محلية سريعة جداً (SQLite)
- بحث فوري حتى مع آلاف المنتجات
- تصميم خفيف وسلس
- استخدام فهارس للبحث السريع

### 🌍 مميزات إضافية
- واجهة عربية RTL كاملة
- عملة شيكل ₪
- ثيم **Liquid Glass** الحديث
- تصميم بسيط وسهل الاستخدام
- مناسب للمتاجر الصغيرة والمتوسطة

## 🛠️ التقنيات المستخدمة

- **Flutter** - إطار العمل الأساسي
- **Dart** - لغة البرمجة
- **SQLite** (sqflite) - قاعدة البيانات المحلية
- **Provider** - إدارة الحالة
- **Mobile Scanner** - مسح الباركود والQR
- **Intl** - التعامل مع التواريخ والأرقام
- **Shared Preferences** - التخزين المحلي للإعدادات

## 📱 متطلبات التشغيل

- Flutter SDK 3.0 أو أحدث
- Dart SDK 3.0 أو أحدث
- Android Studio / VS Code
- جهاز Android (API 21+) أو محاكي

## 🎨 ثيم Liquid Glass

التطبيق يستخدم ثيم **Liquid Glass** الحديث الذي يتميز بـ:
- تأثيرات زجاجية شفافة
- تدرجات ألوان سلسة (Gradients)
- ظلال ناعمة
- رسوم متحركة سلسة
- ألوان عصرية وجذابة

### الألوان الأساسية:
- Primary: `#6C5CE7` (بنفسجي)
- Secondary: `#00B894` (أخضر نعناعي)
- Accent: `#FD79A8` (وردي)
- Background: `#0F0F1E` (أسود مزرق)

## 📝 الاستخدام

### تسجيل الدخول
- أدخل PIN (افتراضي: 1234)
- يمكن تعطيل PIN من الإعدادات

### إضافة منتج
1. اذهب إلى شاشة المنتجات
2. اضغط على زر +
3. أدخل بيانات المنتج
4. احفظ

### عملية بيع
1. اذهب إلى نقطة البيع (POS)
2. امسح الباركود أو ابحث عن المنتج
3. أضف للسلة
4. طبّق خصم (اختياري)
5. أتمم البيع

### عرض الفواتير
1. اذهب إلى شاشة الفواتير
2. اضغط على أي فاتورة لرؤية التفاصيل
3. يمكن عمل مرتجع للفواتير

### التقارير
- عرض تلقائي للمبيعات اليومية والشهرية
- أكثر المنتجات مبيعاً
- تنبيهات المخزون

## 🔒 الأمان

- تشفير PIN باستخدام Shared Preferences
- حماية البيانات محلياً
- لا يتم إرسال أي بيانات للإنترنت
